# Model Card: Applied ML Risk Prediction Demo

## Model Name

`risk_prediction_model.joblib`

## Model Type

Logistic Regression classifier inside a scikit-learn Pipeline with preprocessing.

## Model Purpose

This model demonstrates a supervised binary classification workflow for a portfolio risk prediction project.

## Dataset Source

- Dataset: Wisconsin Diagnostic Breast Cancer dataset
- Source: `sklearn.datasets.load_breast_cancer`
- Data type: public demonstration dataset

## Intended Use

- Demonstrate practical data science and junior ML engineering skills.
- Show reproducible model training, evaluation, documentation, and batch prediction.
- Support job applications by providing readable code and honest reporting.

## Not Intended Use

- Clinical decision-making
- Financial decision-making
- Legal decision-making
- Operational risk scoring
- Any real-world automated decision system

## Features

The model uses 30 numeric diagnostic measurement features from the public dataset. See:

```text
data/processed/feature_info.csv
```

## Target

`risk_label`

- `1`: malignant/high-risk demonstration class
- `0`: benign/lower-risk demonstration class

## Training Method

The training script compares:

- Logistic Regression baseline
- Random Forest classifier

The selected model is chosen using validation ROC AUC where available, otherwise validation F1.

Current selected model:

```text
logistic_regression
```

## Limitations

- This is a small public teaching dataset.
- Results may be optimistic compared with real operational settings.
- The model has not been externally validated.
- Feature meanings require domain context.
- This model should not be deployed for real decisions.

## Ethical Cautions

Risk prediction can affect people if used in real systems. This project is intentionally limited to a public demonstration dataset and should not be treated as a deployment-ready model.

This model is not suitable for clinical use.

## Monitoring And Deployment Considerations

Deployment is hypothetical only. A real project would need:

- External validation
- Calibration checks
- Threshold governance
- Data drift monitoring
- Performance monitoring by relevant subgroups
- Human review and accountability processes
- Legal, privacy, and domain expert review
