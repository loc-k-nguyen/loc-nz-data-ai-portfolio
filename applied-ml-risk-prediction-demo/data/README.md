# Data README

## Source

This project uses the Wisconsin Diagnostic Breast Cancer dataset available through:

```python
sklearn.datasets.load_breast_cancer
```

The workflow does not require a downloaded raw file. `src/prepare_data.py` loads the public dataset from scikit-learn and writes processed CSV files.

Source documentation is bundled with scikit-learn and can be inspected through:

```python
from sklearn.datasets import load_breast_cancer
print(load_breast_cancer().DESCR)
```

## Data Type

Public demonstration data.

This is not private, operational, clinical deployment, customer, or citizen data.

## Dataset Shape

- Full dataset rows: 569
- Columns after preparation: 32, including `record_id` and `risk_label`
- Train rows: 455
- Test rows: 114
- Input features: 30 numeric measurement features

## Target Column

`risk_label`

- `1`: malignant/high-risk demonstration class
- `0`: benign/lower-risk demonstration class

## Processed Files

Generated by:

```powershell
python .\applied-ml-risk-prediction-demo\src\prepare_data.py
```

Files:

- `data/processed/train.csv`
- `data/processed/test.csv`
- `data/processed/feature_info.csv`

## Limitations

- The dataset is small.
- The dataset is not New Zealand-specific.
- The model is a portfolio demonstration only.
- No clinical, financial, legal, or operational decisions should be made from this project.
