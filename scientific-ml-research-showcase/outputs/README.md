# Outputs

Generated outputs from the synthetic scientific ML surrogate workflow.

| File | Purpose |
| --- | --- |
| `metrics.csv` | Validation and test metrics from training. |
| `training_history.csv` | Epoch-level training loss and validation metrics. |
| `prediction_examples.png` | Input, target, and prediction example fields. |
| `error_map_examples.png` | Target, prediction, and absolute error map. |
| `experiment_summary.md` | Human-readable experiment summary and test metrics. |
| `evaluation_metrics.csv` | Metrics from reloading and evaluating the saved model. |
| `evaluation_summary.md` | Reproducibility check from saved model evaluation. |

All outputs are synthetic demonstration results. They are not private PhD results or validated scientific findings.
