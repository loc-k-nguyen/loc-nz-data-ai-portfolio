# Data README

No private data is used in this project.

The dataset is generated by code in:

```text
src/dataset.py
```

## Synthetic Data

The data consists of deterministic synthetic 2D fields:

- permeability-like smooth random field
- source/location Gaussian field
- plume-like target field

The random seed and dataset size are controlled by:

```text
configs/config.yaml
```

## Generated Metadata

Running the project writes:

```text
data/generated/synthetic_dataset_metadata.json
```

This metadata documents that the data is synthetic demonstration data.

## Limitations

- The synthetic generator is intentionally simplified.
- The fields are not real groundwater, environmental, or PhD data.
- Results are only useful for demonstrating workflow structure.
