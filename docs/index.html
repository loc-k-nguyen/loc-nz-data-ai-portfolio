From source to report

A small, inspectable
analyst workflow.

  1. Prepare. Clean the official HUD Metrics sheet with Python, preserving source fields and lineage.
  2. Query. Select each measure with parameterized SQLite queries that fix its unit and population.
  3. Validate. Check schema, numeric values, source vintage, and uniqueness before publishing.
  4. Communicate. Show actual observation dates, coverage gaps, exact tables, and downloadable data.

Source & interpretation

HUD Local Housing Statistics documentation ↗

Source-quality details load with the dashboard.

Measures have different reporting periods. Rent levels can reflect changes in the mix of tenancies. Affordability indices describe change over time, not a cross-area affordability league table. This is descriptive analysis, not a causal estimate or a policy recommendation.

Use the browser explorer above for immediate interaction, or download the verified Power BI report. Both retain the same exact source observations. Percentage shares preserve their source fractions and display as percentages; 0.426 becomes 42.6%.
